## Dataset Download

This folder already contains the ground-truth annotations and sampling metadata for the 200-paper benchmark (checked into the repository):

* `arxiv_urls_1992_2024_gt.csv` — manual ground-truth URL annotations (2,420 total URLs / 2,338 unique), with per-URL location, complexity, and OADS category labels.
* `selected_100_arxiv_ids_set_a.json` / `selected_100_arxiv_ids_set_b.json` — the sampled arXiv IDs for Set A (2016–2024) and Set B (1992–2015), grouped by layout category (single-column, double-column, ETD, scanned).

The **raw source files** (the 200 PDFs and their corresponding LaTeX sources) are not checked into this repository because of their size, and must be downloaded from Hugging Face before running `1_arxiv_200_benchmark_conversions_and_extractions.ipynb`:

https://huggingface.co/datasets/rochanaro/hf-arxiv-url-bench/blob/main/arxiv-200-benchmark/arxiv-url-bench-200-raw-files.tar.gz

After downloading and extracting the archive, place the contents under the repository's `data/` directory so that the directory structure matches the following:

```text
data/
├── 200_sample/
│   ├── arxiv_urls_1992_2024_gt.csv                    # ground truth (already in repo)
│   ├── selected_100_arxiv_ids_set_a.json              # Set A sample IDs, 2016-2024 (already in repo)
│   ├── selected_100_arxiv_ids_set_b.json              # Set B sample IDs, 1992-2015 (already in repo)
│   ├── arxiv_extracted_urls_all_formats_200.json      # generated by notebook 1 (FINAL combined output)
│   │
│   ├── analysis/                                       # generated by notebooks 2 & 3
│   │   ├── arxiv_extracted_unique_urls_all_200_superset.json
│   │   ├── url_format_availability.csv
│   │   ├── all_urls_63_combos.csv
│   │   ├── friedman_all_url_recall.csv
│   │   ├── significance_all_url_recall_holm.csv
│   │   ├── oads_63_combos.csv
│   │   ├── friedman_oads_recall.csv
│   │   └── significance_oads_recall_holm.csv
│   │
│   ├── intermediate_results/                           # generated by notebook 1, one JSON per format
│   │   ├── stage_text_urls.json
│   │   ├── stage_textwal_pymupdf_urls.json
│   │   ├── stage_textwal_pypdf_urls.json
```

Only `data/200_sample/raw_files/pdf/` and `data/200_sample/raw_files/latex/` need to be populated from the Hugging Face download before you start. Everything else — the rest of `raw_files/`, `intermediate_results/`, `analysis/`, and the final combined JSON — is created automatically as you run, in order, `1_arxiv_200_benchmark_conversions_and_extractions.ipynb`, `2_arxiv_200_all_urls_extraction_performance.ipynb`, and `3_arxiv_200_oads_urls_extraction_performance.ipynb`.
